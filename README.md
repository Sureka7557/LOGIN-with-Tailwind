# Login Form with Tailwind CSS

A simple and stylish login form built using HTML and Tailwind CSS. It features a bold design with a pink background, black borders, a yellow login button, and interactive hover effects.

## Features
- Email and password input fields
- Responsive centered layout
- Bold borders and shadow effects
- Interactive hover animations
- Sign-up link

## Technologies Used
- HTML5
- Tailwind CSS v4 (Browser CDN)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Sureka7557/LOGIN-with-Tailwind.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## Preview

The login form uses a vibrant pink, black, white, and yellow color palette with a modern, bold visual style.
